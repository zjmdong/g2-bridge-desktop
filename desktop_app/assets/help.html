第一次使用

  1. 准备 Windows x64 电脑与支持 NVENC 的 NVIDIA 显卡。本版沿用 SDK 的 NVIDIA 编码路径。
  2. 在「设备与驱动」检查环境。缺少驱动时点击「下载并安装驱动」，或选择本地 DJI Assistant 2 消费机系列 2.1.42 安装包。安装需要 Windows 管理员授权。
  3. 将眼镜开机，用支持数据传输的 USB 线连接电脑。建议使用 USB-A 转 USB-C 数据线；仅有 USB-C 接口时可增加合适的 USB-A 转接器。
  4. 在眼镜中进入「更多 → DJI Virtual Flight」。电脑无法替你完成这个菜单操作。
  5. 等待型号、固件检测完成，回到「桌面串流」选择参数，点击「开始串流」。在眼镜中确认画面。
  6. 结束时先点击「停止串流」，再断开线缆。可选择电脑主屏或独立扩展屏；特定软件窗口选择将在后续版本提供。

使用官方工具更新或恢复

  1. 停止串流并退出本客户端，避免和 DJI Assistant 同时占用 USB。
  2. 从 DJI 官方下载页面安装 DJI Assistant 2（消费机系列）。驱动安装与固件更新是两件不同的事。
  3. 保持设备电量充足、供电和 USB 连接稳定。打开 DJI Assistant，按官方界面要求登录并选择眼镜。
  4. 查看设备可用的固件列表，选择与型号匹配的已验证版本。只有官方界面提供降级时才可按该流程降级；若列表没有目标版本，不要尝试其他型号固件，应联系 DJI 支持。
  5. 按官方工具提示完成升级或刷新，过程中不要断电或拔线。
  6. 关闭 DJI Assistant，重新启动眼镜和本客户端，再次检测型号与固件。

常见问题

找不到眼镜

检查电源、数据线与 USB 端口，关闭可能占用设备的 DJI Assistant。避免只充电的线缆。设备连接后客户端会定期重新检测；插着多个受支持设备时请先只保留一台。

设备连接了，但一直等待

确认眼镜已进入 DJI Virtual Flight。USB 连接成功与视频握手成功是不同状态。若提示 d6 或无法退出 Virtual Flight，先停止串流，退出并重新进入该模式；必要时重启眼镜。

黑屏、画面冻结或反复重启编码

先停止串流，降低码率，重启眼镜后再试。SDK 会阻止超过其单帧预算的视频数据。切勿关闭限制或强制使用未验证固件。若设备无法正常启动，请使用官方恢复流程。

NVIDIA 编码或桌面采集失败

确认电脑为 Windows x64，显卡支持 NVENC，安装显卡厂商驱动并保持桌面解锁。可以在高级设置中尝试 Desktop Duplication。远程桌面、受保护内容及某些独占全屏应用可能无法采集。

分辨率为什么只有 1080p？

当前 SDK 的桌面视频输出固定为 1920×1080。0.1.1 保持 SDK 不变，因此只显示这一已验证选项。高分辨率桌面会由 SDK 缩放；帧率、码率仍可调整。

使用独立扩展屏（实验性）

选择「独立扩展屏」，点击「安装扩展屏驱动」，完成 Windows 管理员授权。再点击「启用 1080p 扩展屏」，Windows 会添加独立的 1920×1080 / 60 Hz 桌面，位于主屏右侧。把模拟器窗口拖过去，或用 Win + Shift + → 移动窗口，然后开始串流。可在模拟器内部选择该显示器和 1080p 分辨率。

这由 Windows 虚拟显示驱动提供；USB 仍使用原 SDK 视频协议。主屏无需改成 16∶9。扩展屏固定 60 Hz，推荐串流 60 fps。停止串流不移除桌面；不用时点击「断开扩展屏」。断开前请保存应用工作，Windows 会重新安排其窗口。应用退出也保留扩展屏，可通过 Windows 显示设置断开。

本版内置已签名的 MIT 开源 VDD 25.7.23，保留原驱动与签名，不导入证书或启用测试签名。如果 Windows 拒绝安装，请查看安装错误及上游说明，不要关闭驱动签名保护。检测到其他软件的 VDD 时不会覆盖配置。需要卸载时前往「桌面串流 → 独立扩展屏 → 移除扩展屏驱动」；此操作需要管理员授权，客户端卸载不会自动删除系统驱动。

此功能尚待本机管理员安装与完整硬件显示验证。参考：VDD 源码及说明。主屏采集会等比缩放、补黑边，并固定输出像素宽高比。
